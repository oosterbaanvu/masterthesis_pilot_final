# Data portfolio, lineage and rights

There are **three independent complete-source tables**, two distinct-value benchmark collections, three author-released pattern-field collections, and a conditioned human-candidate release. These are not eleven independent full-table datasets. Outcome columns are excluded from all quality-model features. Customer/producer independence beyond observed source grouping is unknown.

`compatibility_matrix.json` enumerates target units, history, input types and exclusions; `baseline_inventory.json`, qualification manifests, and `pattern_sources.json` pin bytes and observed list positions. The RT physical CSV includes1,048,575 records, mostly empty trailing records; this is not1 million usable columns. Structural exclusions occur before methods see labels; duplicate headers remain separate columns and duplicate occurrences are never collapsed into invented distinct frequencies.

No fourth/fifth unrelated full table was collected just to increase dataset count. RT and ST add a genuinely different publisher-reference task; DOMAINS adds suitable pattern inputs; RIOLU Hospital is related lineage, not an independent new source. Adding more sources only helps when units, contracts, history and reference validity support an actual comparison. Data and model licensing is not inferred from public access or the RIOLU code license.
