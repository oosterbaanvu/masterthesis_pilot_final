# Truth categories and valid denominators

A. **Stipulated contract violation**: independently supplied parsing/requiredness/category/business/linked-table invariant. Historical impossible codes and the synthetic financial fixture belong here. Their success is control validation.

B. **Source-relative alteration**: source bytes/IDs and exact changed coordinates establish that an ingest value changed. They do not establish that the old value was semantically correct, the new plausible value false, or untouched values clean. All360 new logical numeric/category cases pass the target hard contract. P5 lexical alterations have the same limitation; where a true upstream snapshot exists, reconciliation detects every intended change.

C. **Publisher reference**: RT 41 and ST 45 positive distinct values, with ambiguous35/77 values excluded from TP/FN/precision. An alerted ambiguous value still consumes a review. A distinct value has no invented cell frequency. There is no relational M/CDC experiment on fabricated web-table rows.

D. **Independently adjudicated real-world semantic error**: no new comprehensive gold standard was established. Auto-Detect offers human judgments on sampled incompatible pairs, not our independent adjudication or exhaustive cell labels. Historic Hospital/Beers dirty-clean disagreement is reference agreement with the documented caveats.

E. **Unknown or ambiguous**: untouched source cells and off-alteration alerts are unknown burden. They are not automatically objectively false positives. Publisher-relative precision and source-change precision have distinct meanings. We report no pooled F1 across cell/row/value/pair units.

RIOLU default sampling needs385 values without replacement. Smaller distinct populations return null/NOT_APPLICABLE; supported small-sample parameters are a separately named adaptation. Native LUCARIO failures and regex timeouts also remain null with their cause. Null does not mean zero detections. Matched cohort intersections are recomputed before comparing methods; matched denominators often differ from standalone method coverage.

All current sources have been inspected during exploratory work, including public labels in earlier feasibility qualification. No inspected split is retroactively called an untouched confirmatory holdout. Outcome labels, reference corrections and publisher error indicators do not enter the new inference JSON inputs or model fitting. Source values used as regression/classification targets are not independent clean/error labels.
