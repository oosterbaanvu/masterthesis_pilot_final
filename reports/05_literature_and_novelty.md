# Focused literature and novelty assessment

This is a focused original-source review, not an exhaustive systematic review. PDFs were acquired and read locally; URLs/checksums: `manifests/literature.json`. Repositories/revisions: `evidence/source_acquisition.json`. Publication full text and software behaviour are separate evidence.

| Work | Evidence checked | Implication for this thesis |
| --- | --- | --- |
| Abedjan et al. (2016), Detecting Data Errors: Where are we and what needs to be done?, PVLDB 9, 993–1004 | Official PDF, especially §3–4 | Tool complementarity and combinations are already studied. Their ground-truth-informed iterative tuning must not be copied into a held-out evaluation. |
| Pit-Claudel et al. (2016), Outlier Detection in Heterogeneous Datasets using Automatic Tuple Expansion, MIT-CSAIL-TR-2016-002 | Original Git README, paper TeX and running upstream Gaussian fixture | Outlier detection is not synonymous with semantic invalidity; parameter and expansion choices matter. No reimplementation fidelity is assumed. |
| Mahdavi et al. (2019), Raha, SIGMOD, DOI 10.1145/3299869.3324956 | Author-released paper §6.1, appendix and dataset loader | Semi-supervised detector combines base strategies. Beers manually cleaned; Rayyan owner-cleaned; Movies truth derives from duplicates; Tax synthetic. Loader additionally normalizes HTML/whitespace; our raw audit deliberately does not. |
| Rekatsinas et al. (2017), HoloClean, PVLDB 10, 1190–1201 | Official PDF §6 and actual testdata/evaluator | Repair metrics differ from detection. Food/Physicians have partial manual annotations. Released reference formats are not all row-wise wide clean tables. |
| Jäger & Biessmann (2024), From Data Imputation to Data Cleaning, AISTATS, PMLR 238:3394–3402 | Official PMLR PDF and pinned implementation | Explicit clean-history assumption and downstream predictive objective. Dirty transductive benchmark fitting does not inherit the same conformal guarantees. |
| Chen et al. (2025), Auto-Test: Learning Semantic-Domain Constraints for Unsupervised Error Detection in Tables, arXiv:2504.10762v1; PACMMOD 3(3), Article 133 | Original full text §6.1 and §6.6, Table 9–11; benchmark CSVs | Already demonstrates complementary constraints and additional errors over benchmark constraints, with manual re-annotation. Claiming 'AI plus rules is novel' is untenable. Paper states separate RT/ST training corpora; independent release overlap remains unresolved. |
| REIN, Abdelaal, Hammacher & Schoening | Official pinned README, source dictionary, detection/evaluation code | Broad detector/repair/downstream benchmark already exists. README citation is incomplete and venue metadata inconsistent with historical summaries. Original paper bibliographic verification remains OPEN (official EDBT index retrieval attempted; network proxy returned 403); do not invent a DOI or accept README venue as verified. |
| Arocena et al. (2015), Messing up with BART, PVLDB 9(2):36–47 | Official PDF | Controlled errors are useful with a documented generator; they do not establish natural-error external validity. |

The narrow plausible contribution is **review-budget accounting and sensitivity to justified baseline strength**, with explicit information parity, uncertainty strata and error families. It is not a new detector, and incremental detection alone is already demonstrated by closest work. We have not established that this narrower combination is novel; supervisor and targeted forward/backward citation review are prerequisites to confirmation.

Historical evidence was inspected read-only at the two requested branches and default branches of masterthesis/masterthesis3. Reports and machine-readable outputs exist, but their experimental conclusions were not rerun here and are not new evidence. The README's dBoost fidelity claim is tied to a particular adapter and samples in `qualify_pilot_detectors.py`; this new repository uses the original upstream fixture and does not inherit universal 100% fidelity. Our fresh byte audits independently reproduce the previously alleged 509 Hospital changes (508 x-pattern), 948 Rayyan changes, 710 Cars numeric equivalents and 125 non-class Restaurant changes. That is verification of dataset properties, not of historical model-effect conclusions.
